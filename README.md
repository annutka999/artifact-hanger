# «Не сегодня» — первый публичный фрагмент

Простой учебный сайт по заданию «Первый публичный фрагмент».

Файлы:
- `index.html` — короткая рекламная страница;
- `warning.html` — документ (бирка-предупреждение);
- `styles.css` — минимальная адаптивная вёрстка;
- `hanger.png` — изображение вымышленной вешалки;
- `submission.txt` — текстовое обоснование для колонки F.

## Проверка
Откройте `index.html` в браузере. Нажмите «Открыть предупреждение» — должна открыться страница `warning.html`, откуда можно вернуться назад.

## Публикация на GitHub Pages
Создайте публичный репозиторий, загрузите файлы из этой папки в корень репозитория. В Settings → Pages выберите Deploy from a branch, ветку main и папку /(root). После публикации проверьте публичный адрес без авторизации и на мобильном экране.

ZIP-архив является резервной копией. Проект — дизайн-фикция; заявленные свойства вешалки не существуют.
